## Usage Instructions

1. Copy the relevant prompt template
2. Replace placeholder text in [BRACKETS] with specific information
3. Paste into VS Code where you're working with the Confluence MCP integration
4. Let GitHub Copilot generate the content
5. Review and refine the output
6. Use the MCP server to upload directly to Confluence

## Tips for Better Results

- Be specific about the Confluence space and content type
- Mention formatting requirements (storage format, macros, etc.)
- Include context about your team, project, or organization
- Specify any style guidelines or templates to follow
- Ask for specific Confluence features (tables, expand macros, etc.)
